# 声律场 · 口语发音与韵律练习工作台

使用 Svelte 与 Skeleton 从零实现的口语练习工作台。学习者可以录入句子、划分意群并标注重音、停顿和语调，随后录音、选择回听范围、逐段比较偏差；教师反馈与错词分类会和具体尝试、意群绑定。

## 功能

- 句子录入、标点智能切分、意群增删与排序。
- 逐意群标注重音词、重音强度、停顿毫秒数和语调走向。
- 本机版本库：手动（或 ⌘/Ctrl+S）把标题、原文和各意群的重音、停顿、语调固化为一版；列表显示保存时间、来源与相对上一版的改动处数及明细。
- 打开任一历史版本前会先自动留存当前稿；恢复后的标注可继续编辑、录音，该版保存时的评分、错词和教师反馈仍按当时的意群原样显示。
- 录音统一存入独立录音库，各版本通过录音引用共用同一份尝试，保存或复制版本不重复占用空间；移除旧版本只删除该版快照，录音保留。
- 旧练习首次打开时自动迁移为版本库并生成第 1 版，原有录音搬入录音库。
- 调用浏览器麦克风录音，支持多轮尝试；未授权麦克风时保留可校对的离线模拟轮次。
- 每一轮尝试独立保存回听起点、终点、准确度、节奏、偏差、自评和错词分类。
- 教师可按意群留下多轮反馈。
- 练习进度、目标轮次、准确度、偏差和错词分类统计。
- 使用 IndexedDB 持久化录音、版本库和全部标注，网络中断时继续编辑，不会因刷新丢失。
- Service Worker 缓存应用壳，已打开的生产页面可离线访问。
- 响应式手机/桌面布局和键盘工作流。

## 技术栈

- Svelte 4
- Vite 5
- TypeScript
- Skeleton 2
- Tailwind CSS 3

## 本地开发

```bash
npm install
npm run dev
```

Vite 开发服务器使用本地端口 `5175`，该端口不构成宿主映射。容器生产环境仅监听 `80`。

## 生产构建

```bash
npm install
npm run build
npm run preview
```

构建结果位于 `dist/`。

## Docker

```bash
docker build -t sologsb-1018 .
docker run --rm -p 10018:80 sologsb-1018
```

最终镜像使用 nginx 在容器 `80` 端口提供构建产物。宿主端口由根编排文件维护，源码和 Dockerfile 没有硬编码宿主端口。

## 本地数据与麦克风

- 录音 Blob 存放在 IndexedDB 独立录音库，版本快照、标注、尝试、反馈和进度存于练习库；多个版本共用同一条录音，不重复占用空间。
- IndexedDB 不可用时会退化为 `localStorage`，但浏览器安全限制下不保存原始录音 Blob。
- 从旧版升级时，首次打开会自动生成初始版本并把原录音迁入录音库。
- 麦克风从未上传到服务器；清除站点数据会永久删除本机练习。
- 生产页面首次加载后由 Service Worker 缓存，离线状态仍可继续标注和录音。
